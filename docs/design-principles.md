# Design Principles

1. **Feasible within 6 months.** If a component cannot be bought off the shelf, it is out of the first revision.
2. **No corporate manufacturing.** Laser cutting, 3D printing, M3 screws.
3. **Honest constraints.** If something does not fit inside the case, it is an external accessory, not a feature.
4. **Silence.** Zero fans in the first revision.
5. **Isolation.** Every board is an independent node with its own storage.
